Telco Customer Churn Analysis Dashboard

📊 Project Overview

This project focuses on analyzing customer churn behavior in a telecom company using Power BI.
The dashboard provides interactive visualizations and business insights to help understand customer retention, churn patterns, and revenue impact.

🚀 Objectives

Analyze customer churn trends
Identify factors affecting customer retention
Monitor revenue and subscription behavior
Create interactive business dashboards for decision-making

📁 Dataset Used

Dataset: Telco Customer Churn Dataset
Contains customer information such as:
Customer demographics
Monthly charges
Contract type
Internet services
Payment methods
Churn status

📌 Dashboard Features

✅ Total Customers KPI

✅ Churn Rate Analysis

✅ Monthly Charges Insights

✅ Contract Type Analysis

✅ Customer Retention Overview

✅ Payment Method Distribution

✅ Interactive Filters & Slicers

✅ Pie/Donut Charts, Bar Charts & KPI Cards

🛠️ Tools & Technologies

Microsoft Power BI

Excel / CSV Dataset

Data Cleaning & Transformation

Data Visualization

📈 Key Insights

Customers with month-to-month contracts show higher churn rates

Higher monthly charges are associated with increased churn

Electronic check payment users have higher churn probability

Long-term contract customers are more likely to stay
